# Portfolio design

Use a quiet, compact layout with warm paper (`#f7f8f5`), dark green ink
(`#263b32`), muted text (`#66736c`), and restrained borders (`#dce3dc`).
Use system fonts, a 1040px content area, and responsive gutters.

The header contains the name, four destinations, and one language switch.
Order destinations as research, education, personal information, and projects.
Use the footer for thesis, GitHub, email, and published notes.

The homepage contains one introduction, three featured projects, and a research
link. Move full paper citations, education, skills, and secondary projects to
their own pages. Project implementation details expand on demand. Do not add a
second navigation bar, a sidebar, or repeated sections to the homepage.

Keep job direction explicit: Backend / Cloud. Label MVPs and research
prototypes accurately. Retain English paper titles and author order in all
interface languages. Keep expected graduation visibly separate from a
completed degree. Never claim ownership of the removed KCI publication.

Language selection persists across pages. Links use real URLs, including
unmodified `/thesis/` navigation to the separate project. Respect reduced
motion, visible keyboard focus, mobile layouts, and semantic headings.
